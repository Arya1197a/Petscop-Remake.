# Echo Room — دارایی‌های اولیه

این پوشه شامل بافت‌ها و نمادهای SVG اختصاصی برای نمونه‌ی اولیه‌ی بازی است:

- `textures/floor.svg`: بافت کف شطرنجی تاریک
- `textures/wall.svg`: بافت دیوار فرسوده
- `textures/door.svg`: تصویر ساده‌ی در
- `icons/mysterious-symbol.svg`: نماد مرموز اختصاصی

## استفاده در Godot

فایل‌های SVG را می‌توان مستقیماً به‌عنوان Texture در `StandardMaterial3D` استفاده کرد. این دارایی‌ها برای این پروژه ساخته شده‌اند و از فایل‌های اصلی Petscop کپی نشده‌اند.

## قوانین پروژه

1. این پروژه یک اثر فن‌مِید/الهام‌گرفته است و نباید خود را اثر رسمی Petscop معرفی کند.
2. از ویدئو، موسیقی، مدل، تصویر یا کد اصلی Petscop بدون اجازه استفاده نمی‌کنیم.
3. نام‌ها، شخصیت‌ها، داستان، نمادها و دارایی‌های جدید را تا حد ممکن اختصاصی طراحی می‌کنیم.
4. برای انتشار عمومی، مجوز دارایی‌های شخص ثالث باید بررسی و در همین فایل ثبت شود.
5. این فایل‌های SVG را می‌توان برای همین پروژه استفاده و ویرایش کرد.
